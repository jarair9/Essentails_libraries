# Essential Libraries

A comprehensive learning repository covering the foundational tools and mathematics for machine learning and AI engineering.

## Contents

### Learning Guides
- **AI_ENGINEERING_GUIDE.md** - Complete AI learning roadmap from beginner to expert, covering:
  - Mathematics foundations (Linear Algebra, Calculus, Probability)
  - Machine Learning fundamentals
  - Deep Learning & Neural Networks
  - Generative AI, NLP, and Computer Vision
  - MLOps and deployment

- **complete-math-for-ml.md** - In-depth mathematics reference for ML, covering:
  - Linear Algebra (vectors, matrices, SVD, eigendecomposition)
  - Multivariable & Matrix Calculus
  - Probability Theory & Statistics
  - Optimization Theory
  - Statistical Learning Theory
  - Stochastic Processes & Differential Equations
  - Numerical Computing

  - Filtering with logical conditions
  - Aggregate functions and grouping
  - Data cleaning techniques

## Getting Started

1. **Set up environment:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   # or: source .venv/bin/activate  # Linux/Mac
   pip install numpy pandas jupyter
   ```

2. **Run notebooks:**
   ```bash
   jupyter notebook
   ```

3. **Follow the learning path:**
   1. Start with `complete-math-for-ml.md` for mathematics foundations
   2. Study `AI_ENGINEERING_GUIDE.md` for the complete roadmap
   3. Practice NumPy fundamentals in `numpy/Chapter1/`
   4. Master Pandas using `pandas/study_guide.md` and `Practice.ipynb`



4. **Download PDF extension**
  - For Viewing notes You need to install PDF Extension in IDE.

## Requirements

- Python 3.8+ or Any version Which You are confortable with.
- NumPy
- Pandas
- Jupyter Notebook
